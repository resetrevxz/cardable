## Final evidence and removals

One isolated Chromium `file://` session used the real entry with `?dev=1`, isolated saves, local representative owned cards and actual UI actions. No screenshot, recording, profiling, legacy suite or new test file was used. Reload occurred within that same session. Tutorial Standard hold/reservation/reload/Keep/completion, replay with forced Picker override, narrow 430px Skip and reduced-motion Escape cleanup passed. Full tutorial per-step/all-tier/low-FPS matrix remains unverified.

`checkStability()` passed 60 assertions in 2.4 ms after repairing its incomplete fresh-save fixture. The first attempt stopped because the dev encoder requires `packs.ready`; this was a check-fixture failure. There was one failed invocation and one completed invocation after repair (a narrow retry beyond the nominal once-only request, not extra suites). The completed check covers tier/typed/protection rules, wallet arithmetic/cap/daily totals, atomic payment failure and persisted/idempotent tier unlock, and percentile/low-FPS math.

Application interaction produced no JavaScript exceptions and no HTTP(S) request. Studio produced four headless OpenGL driver warnings about GPU stalls during existing `ReadPixels` work. An attempted verification-only local `fetch` of the repaired check produced two CSP console messages (`connect-src 'none'`); no game feature performed this fetch. The check was then loaded using its local classic-script path. These warnings are recorded rather than classed as a perfectly warning-free console.

Advanced counts were inspected during Studio and replay; the HUD stays visible across both scopes. Sleeping/hidden work and the 0.3 ms target are source contracts, not measured CPU or leak certification. RAF/timer/WebGL counts observe handles created after Advanced is enabled; the display and report label that limit explicitly. Native lifecycle/notifications/tray/mirrors/mini, photos, physical DPI and full cinematic matrix remain outside this session's acceptance.

Removals: active Journal data/engine/UI/CSS/dev-check loaders; Journal inventory/detail/palette/navigation/help routes; obsolete detail History segments/styles; the duplicate reward-flight subscriber and its CSS. Original code/spec bytes remain under `archive/card-history`. Passive saved history, achievement receipts and Studio editing history remain intact. A missing public detail-close adapter used by existing commands was exposed, and reachable command-card links now preserve the sheet detent.

Version remains 1.1.0, save schema remains 5. Unreleased notes ship in markdown and bundled browser data. Main's concurrent achievement-color commit was retained during the worktree rebase. Additional tunable replay defaults: Basic 10, Common 15, Uncommon 20, Rare 30, Super Rare 50, Unusual 60, Double Super Rare 80, Legendary 100, Exotic 250. Mythical 150, Ascendant 400 and Secret 1000 follow the spec examples. Delete refund remains zero.

Final source review also constrains wallet/delete/replay controls to the native composed scene safe rectangle. The performance HUD remains in the actual window coordinate space and reports the requested native UI size; native UI-scale/DPI acceptance is still unverified. Dead prior wallet receipt/wind styles were removed.
