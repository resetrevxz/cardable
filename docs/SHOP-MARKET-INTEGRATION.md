## Merge sequence and gates

1. At owner approval, refresh both branch tips and compare overlapping files again. Integrate additive script/style/navigation entries first, then state and wallet adapters, then pack/opening hooks. Resolve conflicts line by line. Keep Market's simulation and Global realm data partitioned from Shop's local collection.
2. Decide the natural pack reward centrally. This Shop branch leaves the existing 200-Credit natural reward alone; its purchased Titan path explicitly gives zero. Future Market work may remove the natural reward. Update any wallet HUD, tutorial copy, tests and value assumptions together.
3. Establish a transfer policy before exposing Shop copies to Global Market. A local Market simulator may use the same local Credits and instances, but Global ownership requires a separate authoritative settlement. The legacy one-time migration is finite onboarding, not an import loop for Shop purchases. `shopOfferId` and `shopEntitlementId` are provenance, not proof of online ownership.
4. Run a combined save matrix: old save without Shop/Market, Shop-only save, Market-only save, both trees, purchased Titan pending before and after reveal, invalid storage, import/restore and duplicate serials. Then run ordinary pack cadence/reward, Shop holds, Market preview/settlement, and packaged offline startup. A successful source browser run is not a packaged pass.

No Market merge, push, release or deployment was attempted in Stage 4.
