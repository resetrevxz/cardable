## Contracts and assumptions

New settings are optional under save.settings; journal normalization is explicit. The save schema stays 5. Defaults preserve Medium, familiar shortcuts and existing motion/cutscene settings. Per-rarity Inherit and Studio Current values preserve legacy preferences. Default-off proximity chrome avoids changing established menu behavior. Native window shortcuts are owned by the renderer registry; only native development DevTools shortcuts remain intercepted. Mini receives a narrow validated effective-binding map. Unlimited native launch flags are stored separately and applied only at startup; Restart flushes the save first. The reset-controls launch flag works at first launch and on a second-instance request.

Old player-facing changelog files and bundled entries are replaced as requested; historical engineering/spec/archive evidence and published GitHub releases remain recoverable.
