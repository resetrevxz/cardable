# 2.7.0 — Quiet card detail

Reworked the right-hand detail panel into Overview/History tabs, a three-chip provenance row with a glass metadata popover, additional specs only, a compact copy selector and one primary Inspect action. Flip, Favorite and More retain access to serial copying, card-data export, collection membership and safeguarded deletion of the selected copy. Navigation now flanks the card; the R hint sits below it. Detail hides neighboring shelf cards, fits its default desktop panel at 720p without scrolling, and stacks below the card under 900 px.

Testing: One offline game session checked normal and variant cards, desktop/narrow bounds, tabs and keyboard-accessible metadata popovers; no horizontal overflow, clipping or game console errors. No suites, test files, screenshots or profiling.
