# Done

- **F1 — collection handoff:** the entire original card root fades and scales for 150 ms, then becomes `visibility: hidden`. Its animation and pointer participation stop together. The toast waits for that handoff before becoming visible, so it cannot appear behind residual card text. Toast and flight thumbnails use the card factory's new permanently-lite, art-only presentation; text/props are removed, other decorative layers are hidden, and each thumbnail is clipped to its own rounded rectangle. Corner radii derive from `--r-card` and the actual source width. A single-card toast contains only its thumbnail, card name and **Added to inventory**.
- **F2 — toast surface:** the glass element and its two content slots are created at boot. The hidden surface retains its display box, sits off-screen with `visibility: hidden`, and moves in using transform and clip-path on the same element. Its backdrop-filter never receives an opacity animation. `will-change: transform` exists only during entrance/exit. Reset/expiry destroys only the thumbnail view, retaining the pre-mounted surface and slots.
- **F3 — click breaths:** `config.dots.ripple` contains speed **320 px/s**, lifetime **1100 ms**, peak alpha **0.28**, full ring width **24 px**, radius cap **240 px**, echo scale **0.30**, delay **200 ms** and simultaneous cap **3**. The cap includes delayed echoes, evicts oldest rings, and applies to the existing pack-pulse queue too. Ring intensities combine by maximum rather than addition. Reduced motion creates no rings.
- **F4 — exclusive opening pulses:** charging, draining and dissolving fade the frozen cursor dot layer out over **200 ms**. Moves cannot create hover/trail energy or clicks during these states. Only pack pulses remain; tutorial/reveal halo energy fades with the ambient layer to prevent another stationary dot layer. Cutting or idle restores normal dots over **300 ms**. Cursor glow is unchanged. Visible-time fades pause when the tab hides; expired rings are discarded.
- **F5 — calm scramble:** each SVG letter has a measured fixed slot based on its complete glyph pool, centered text, 2 px padding and 2 px tracking. No glyph squeezing, scaling, weight changes or shared wave. Independent 180–520 ms holds and 320–420 ms swaps use the exact `--ease-out` cubic curve, 35% vertical travel, opacity and at most 2 px blur. At most two swaps run at once. Leave returns to **cardable** in randomized batches without jumping an in-flight composite. The rare queued idle run affects one letter; reduced motion stays at the original word.
- **F6 — satin pack rig:** body, edge, SVG crimped seals, engraved c mark, **STANDARD PACK** label, circuit traces, cursor specular, diagonal sweep and reflection share one pose. Ready-arrival lift also acts on this pose. The keyboard focus ring follows the front rig. Ground shadows are separate siblings; rising makes them smaller/lighter, lowering larger/darker. The pack is **180 × 266.4 px** (5:7.4), floats ±5 px on a six-second cycle, and leans with the shared **140/16/1** spring capped at **8°**. Rear stock stays smaller/dimmer with its own phase. Waiting fluid, single ready sweep, stock and timer rules remain intact. The shared opening wrapper builder receives the same original seal/mark/trace design.
- Added `tools/check-visual-fixes.cjs`. **15 focused F1–F6 checks**, **236 existing Stage 1–8 behavior groups**, and the **six Stage 0 console checks** pass. All **67 JavaScript files** pass syntax checks.
