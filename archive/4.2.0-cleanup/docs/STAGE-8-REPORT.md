# Done

- Implemented Stage 8 save-file export/import using local JSON files and blob downloads. **Save & display** is available in the Collection header and dev gallery; Ctrl/Cmd+, opens it from the menu or a revealed card. The menu keeps its existing quiet layout.
- Imports are parsed as data, migrated and validated before any write. The dialog previews collection/instance/pack counts and reserved-reveal status, then offers **Replace save**. A previous-save copy is stored at `cardable.save.before-import` and is available through **Export previous save** for an undo import. Failed backup or replacement writes preserve the current collection and reveal progress. A successful import resets presentation and resumes the exact reserved result, including multi-card Keep progress, without resolving another pull.
- Strengthened corrupt-save handling for invalid JSON, root shapes, counters, stock, tutorial/settings and pending records. Unreadable local saves are copied to `cardable.save.corrupt` and replaced with a fresh save. A clean recovery notice offers a backup download. Failed ordinary storage writes retain the session fallback and show an actionable export notice. Dev console checks restore their temporary recovery state so they do not produce a false notice.
- Added a full motion/focus pass: the system preference remains the default, with persistent Follow system / Reduced / Full choices. Reduced cards now have zero tilt, lift, parallax and sway; finish animation, ripples, particles, glyph rolls, rubber-band and CSS transform transitions are disabled or replaced with fades/static states. Hidden tabs explicitly pause CSS engraving animations as well as the shared scheduler.
- Added consistent 1 px white-at-60% focus outlines and 3 px soft glows. Collection, detail and save dialogs contain keyboard focus and restore it on exit; nested settings does not consume the underlying screen's Esc. Waiting packs announce their disabled state. Missing-card generation labels and peripheral stack counts retain readable contrast. Static token contrast checks exceed 4.5:1 on the dark surfaces tested.
- Added bounded, labeled frame profiling to the shared scheduler. Profiles include raw frame cadence, p95, slow-frame count and per-subscriber JS costs; long frames are reported before animation delta clamping. Use **Profile current screen · 5 s** or Ctrl+Shift+P in dev mode. Gallery/shelf measurement buttons also capture the profiler. Hidden-tab or motion changes invalidate samples.
- Removed avoidable work: card pose writes skip unchanged values; dot coordinates are cached on resize; ripple bursts are bounded at 48; stable tutorial geometry is reused instead of forcing repeated layout reads. The sheet keeps its existing settled-chrome guards, ±6 window and single-full-card limit.
