# Archived Card History

The 1.2.0 Part 1 update retires the collection Journal UI, event consumers, developer check and original spec. These files are historical reference and are excluded from the runtime and app packaging. Studio editing history and achievement receipts remain separate active systems.

Existing `save.journal` data remains intact through save loading, JSON export/import and backups. No active consumer reads it. Restoring this feature would require new authorization and current integration work.
