Cardable for Windows

V1.0.0

The recommended installer includes the complete game and Electron runtime. It adds your desktop and Start Menu shortcuts.

Download installer ↓Prefer the complete app folder? Download ZIP ↗

For the ZIP, extract the entire folder and open Cardable.exe. Keep its resources and DLLs together. Folder builds use manual updates.

Release notes & all downloads ↗
  1. 01

    Get the Windows installer.

    Download from the official GitHub release. This first community release is unsigned; Windows may show an unknown publisher. Verify the source before continuing.

  2. 02

    Install for your Windows user.

    Run the installer, then open Cardable from your desktop. Close an existing Cardable session normally before updating.

  3. 03

    Make yourself at home.

    Start with Medium, or choose Low/Very Low for lighter devices. Your collection saves locally; export a backup in Settings → Data.

A FEW THINGS TO KNOW

Before the first pull.

Need a hand? ↗
Can I play without an internet connection?+

Yes. Cards, fonts and game content are included. Installed builds can check GitHub for updates when online; collecting and opening work offline.

Can I bring my browser save?+

In the browser game, use Settings → Data → Export save. In the desktop app, import that JSON and confirm the preview. Studio photos are stored separately: download them from the Album first.

How do updates work?+

Installed builds check for newer releases and download them in the background. A ready update installs after a successful save when you normally quit. ZIP builds use a new full-folder download. For the reset from older 4.x builds to v1.0.0, run the new installer once; automatic updates won't downgrade the version.

What if the game feels slow?+

Try Low, then Very Low. You can also lower the FPS cap, pause visuals when unfocused and sleep the hidden window. Safe Mode and bundled desktop help are available inside the game.

Is this an official hardware-brand game?+

No. Cardable is an independent fan project. Hardware names, logos and photos belong to their respective owners. There is no affiliation or endorsement.
