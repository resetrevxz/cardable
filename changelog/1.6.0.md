# Cardable v1.6.0 — Blue hour

Rare now opens with pale-blue light from both sides, its original four-point cloud star, a cloud timelapse that accelerates into a star break, and a growing blue wash before the card reveal. Full runs for 5.43 seconds; Short uses the shared shortened clock. Reduced motion, Off and Very Low keep the calm still route.

Reduced motion is Off by default. Windows setup offers a checkbox to turn it on for a new collection, and the in-game setting remains available. Old Auto defaults become Off; saved On choices stay On. Saves and the save schema are unchanged. This release is unsigned.
