# Cardable 4.0.0

Cardable now runs as a Windows desktop application with the existing game, cards, pack openings, collection and creator tools.

- Native window controls, fullscreen and safe window restoration.
- Save backups and recovery in the desktop data folder.
- Cardable update controls, diagnostics and optional Discord Rich Presence.
- Offline browser play remains supported.

Public update and Discord availability depend on the distribution build's public configuration. This development build has no release repository or Discord Application ID configured.
