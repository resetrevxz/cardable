# Cardable v1.0.3 — Sovereign Silicon & The Patch Notes Remake

Cardable introduces a completely reimagined Patch Notes Hub built with an Apple- and Vercel-inspired design language. Browse new additions, variants, and crates through responsive inventory card showcases with real-time 3D hover and click inspection. Explore interactive balance tuning accordions featuring categorized stat diffs, buff/nerf indicators, and comparative meters.

- **Inventory-like showcase**: High-impact showcase cards with authentic rarity halos, custom finish shaders, hardware specification chips, and instant specimen inspection.
- **Interactive balance accordions**: Fluid collapsible sections detailing silicon thermal targets, clock ceilings, and pack drop rates with color-coded buff/nerf tags and visual comparison bars.
- **Dedicated HUD access**: Special Patch Notes button mounted right beside the Credits display on the main game HUD, plus quick navigation in Settings → About beside Credits and licenses.
- **Interactive Mode playground**: Real-time 3D card tilt driven by cursor gyroscopics, interactive balance simulation, and specimen test flips.
- **Search, sort & view more**: Real-time multi-criteria filtering across all historical releases, sort order controls, and expander toggles for high-density browsing.
- **Future update standards**: Formalized patch notes authoring guidelines in AGENTS.md ensuring all future releases maintain rich structured records in src/data/patch-notes.js.

The game remains an offline Windows x64 collector with identical save schema, runtime boundaries, and desktop identity.
