# Cardable 4.2.0

Desktop delivery, player help and explicit save recovery, with the existing four-tier rendering optimizations retained.

- Start playing directly from welcome, or optionally import a browser save through the existing preview and confirmation.
- Find bundled How to play and Desktop help in Settings or the command palette, including shortcuts, graphics, saves, separate photo downloads and recovery.
- Keep unreadable save originals while saving and pack opening pause for an explicit recovery choice. Confirmed import/restore/reset retain their existing safeguards.
- Use clearer startup/storage guidance, save/log folders, diagnostics and one-session Safe Mode through existing desktop services.
- Supply an offline Windows x64 installer configured for one-click per-user setup, normal shortcuts, manual app closing during upgrade and retained player data.
- Build repeatable local deliveries with verified installer/preview/shortcut hashes, transactional handoff and exact owned cleanup.
- Consolidate current documentation and preserve historical reports/QA in an indexed archive with provenance. Keep registered worktrees and incoming specs intact.

The save schema, app identity, pack rules, deterministic reservations, exact-once gameplay rewards, collection/Studio data and graphics presets remain unchanged. Public downloads/live updates, signing and live Discord still require owner configuration. Local unsigned build success is not installer-upgrade, hardware/240 FPS or full cinematic acceptance. See alpha-updates/4.2.0-cleanup/D-DELIVERY.md and docs/ROADMAP.md for scoped evidence and remaining gaps.
