# Cardable 4.1.1

Graphics and desktop performance maintenance for Very Low, Low, Medium and High.

- Fix a layout event feedback loop across desktop and browser play. Real resizing and scale changes still update the composition.
- Reduce repeated desktop IPC/taskbar work and Mini surface updates. Custom graphics choices now reach Mini mode.
- Keep the existing inventory, Settings and cinematic rendering improvements, frame caps and background controls.
- Preserve pack rules, deterministic reservations, exact-once rewards, collection data and save schema.

See docs/OPTIMIZATION-4.1.1.md for measured results, regression coverage and device limits. Display cadence and scene-dependent performance vary; this release does not promise 240 FPS on every device.
