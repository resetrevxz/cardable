# Cardable v1.0.0

Cardable's first public release brings the existing GPU collection game to Windows with an offline installer and a complete app-folder download. Public version numbering starts again at v1.0.0; this carries forward the existing game rather than resetting player progress.

## What's included

- GPU cards with rarity-specific materials, cosmetic variants and cinematic openings.
- Standard, Rare, brand, Classic, Royal, Titan and Picker pack families.
- Shelf/Grid collection browsing, card detail, History, achievements, Inspect and Director.
- Very Low, Low, Medium and High graphics presets, independent FPS limits and hidden/unfocused-window settings.
- Windows desktop shortcuts, Mini mode, bundled Help, explicit save recovery and configured installed-app updates.
- A public download page, installer, complete Electron folder ZIP and checksum manifest.

## Install

Download **Cardable-Setup-1.0.0.exe** and run it for your Windows user. No Node.js, npm, terminal or account is required. This community build is unsigned; Windows may show an unknown publisher. Verify that your download comes from resetrevxz/cardable before continuing.

For the folder build, extract **Cardable-1.0.0-Windows-x64.zip** completely, then open **Cardable.exe**. Keep all resources, DLLs and locale files together. Folder builds use manual updates; the installer is recommended.

## Save compatibility

Save schema, app identity and Windows user-data identity stay unchanged. Existing 4.x installations need this installer once because normal update checks do not downgrade to 1.0.0. Close Cardable normally before setup. Export important progress in Settings → Data first, and download Studio photos separately; photos are not in JSON exports.

## Known limits

This release is unsigned. Data, source/resource integrity and packaging checks do not certify installation/upgrade execution on a clean profile, hardware performance or the full cinematic/accessibility matrix. The repository's BUGS and ROADMAP documents retain those acceptance gaps. Audio, trading, a market, accounts and cloud saves are unavailable.
