# Cardable v1.1.0 — Director Rework

Director's already integrated A–E work reaches the public release: scene authoring, Simple/Pro workspaces, preset libraries, editable animation and camera paths, grading and refinement, expanded output tools and Album browsing. These features come from current main; the unfinished Patch Notes 2 / 1.0.3 branch is excluded.

The website keeps Cardable's monochrome gallery and becomes one continuous scroll journey. The same live card moves from arrival through the actual Rare pack construction, a back-first cinematic reveal, five real material states, the collection and its demo Record. Four full Safe rarity worlds can be scrubbed, watched and replayed. Dedicated Download, Collection, Worlds and Game pages provide useful destinations.

- Real game art, masks, pack construction, finishes and authored cinematic descriptors, with locally bundled fonts and GSAP/ScrollTrigger.
- Reversible choreography, material interpolation, pointer and drag reactions, keyboard controls, chapter navigation and shareable catalog state.
- Working rarity/vendor/search filters, Shelf/Grid browsing, card selection, flips and serial copying.
- Quiet installation, full-folder ZIP, update and separate save/photo backup guidance, plus release/checksum links.
- One focused live card and at most one cinematic canvas, bounded rendering, hidden/offscreen suspension, reduced-motion and static fallbacks. No audio or game state is loaded by the website.
- Website integration uses site/home.html; the original game index.html, legacy site/index.html and game/test files are preserved. Only the required app version metadata changes to 1.1.0.

This release is unsigned. Windows installer execution and a real installed-app update remain separate, unverified acceptance steps. Director milestone F's full visual/accessibility/bug and export acceptance is still pending; this release does not certify that matrix. Keep backups of progress and Studio photos before changing installations. Older 4.x installations need the 1.x installer once; app identity and save schema remain unchanged.
